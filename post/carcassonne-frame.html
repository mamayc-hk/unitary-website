卡卡頌卡磚保護框 V9 —— 由 v1 到 v9，9 次迭代嘅完整設計記錄

卡卡頌（Carcassonne）係一款經典嘅 tile-laying game，最大問題係玩緊嗰陣啲 tile 好易移位。一唔小心吹氣或者撞到枱，成個 board 就亂晒。

玩到中段先係最痛：board 越鋪越大，手同衫袖好容易掃到邊緣嗰幾塊，一移位就要重新數分。而且卡磚用得多，邊角會磨損發白，幾十次之後就會睇得出。

市面上有磁石版本嘅保護框，效果好，但成本高、厚度大，仲要另外買磁石。所以我決定自己設計一款 3D 打印保護框。由 v1 到 v9，經過 9 次迭代，終於做到我想要嘅效果。

本文會完整公開：為咩卡卡頌特別需要保護框、設計上嘅四個約束、實際尺寸表、v1 到 v9 三次失敗階段、PETG 打印設定，同埋三項實測結果。

為咩卡卡頌特別需要保護框

卡卡頌係 tile-laying game，每塊卡磚獨立放置，冇固定槽位。呢個設計令遊戲好玩，但同時令每一塊卡磚都可以被移動。

  • 冇固定位置 — 冇槽、冇卡榫，輕微碰撞就會位移
  • 標準尺寸 45mm × 45mm — 所有版本同擴充都一樣，所以配件可以通用
  • board 越鋪越大 — 中後期橫跨半張枱，邊緣最易被掃到
  • 卡磚會磨損 — 邊角反覆碰撞會發白、起毛

保護框嘅作用係一石二鳥：固定卡磚位置，同時將卡磚嘅邊角包住，減少磨損。

市面方案比較

決定自己設計之前，我比較過幾種做法：

方案 成本 厚度 可以自己加印 需要額外零件
磁石框 較高 較厚（磁石佔位） ❌ ✅ 要買磁石
木質訂製 高 中等 ❌ ❌
亞加力 中等 視乎厚度 ❌ ❌
3D 打印框架（UNITARY） 低 薄 ✅ 要幾多印幾多 ❌ 唔需要

關鍵差異唔係「邊個靚」，而係厚度同可擴充性。磁石方案會令整疊卡磚厚咗，盒蓋可能蓋唔實；而且你想玩多幾隻擴充，就要再買一套。

設計上嘅四個約束

  1. 緊配合 — 卡磚放入去唔會鬆，但亦唔會緊到刮花
  2. PETG 材質 — 比 PLA 韌，唔易裂，適合反覆裝拆
  3. 要夠薄 — 唔可以令疊高嘅厚度明顯增加
  4. 可以自行打印 — 要幾多印幾多，覆蓋 base game 加擴充

第 1 點同第 3 點係互相拉扯嘅：要緊就要厚牆，要薄就要薄牆。而薄牆就代表會裂。呢個矛盾就係 v1 到 v9 嘅全部故事。

公差係整個設計最關鍵嘅一個數字。太鬆：卡磚會搖，保護框冇作用。太緊：卡磚入唔到，硬推就會崩角。實際數值要按你部打印機嘅收縮率微調 —— 建議先印一兩個試手感，唔好一開始就印一板。

九次迭代：太薄、太厚、到手感

由 v1 到 v9 最大嘅改進係 壁厚同卡榫位嘅完美分配。整個過程撞過三個方向，每個方向都係死路，直到最後將兩者一齊睇。

方向一：追求薄 → 裂

最初嘅想法係「越薄越好」，因為唔想增加疊高厚度。結果牆太薄，裝拆幾次就出現裂紋，有幾塊直接斷咗。太薄會裂、會缺失，呢個方向行唔通。

方向二：反過來加厚 → 卡榫變形

之後反過來加厚。強度夠，但太厚會卡榫變形卡唔入，硬塞就會損壞卡磚。加大牆厚並唔等於解決問題。

方向三：重新分配壁厚同卡榫位

最後一輪唔再單獨調牆厚，而係將壁厚同卡榫位一齊睇。太緊會損壞卡磚，太鬆又會甩 —— 最終版終於做到「啪」一聲就 fit 到位嘅手感：唔需要用力，但亦唔會鬆。

呢 9 版教識我一件事：牆厚同緊度唔係兩個獨立參數，佢哋係同一件事嘅兩面。單獨調任何一邊，都只會將問題推去另一邊。

打印設定（PETG 參考值）

以下係一個可以直接用嘅起始設定。唔同打印機熱補償唔同，第一次印建議先印一兩個試手感，再決定要唔要微調。

參數 建議值 原因
層高0.2mm精度同時間平衡
外牆層數3 道韌性主要來自外牆
填充15–20%保護框唔受大彎力，唔需要高填充
噴嘴溫度240–250°CPETG 標準範圍
熱床80°C提升第一層附着力
風扇30–50%全開會令層間結合力下降
支撐不需要垂直外牆結構，加支撐只會留痕
打印時間視乎一板排幾多個視乎一次印幾多個

為咩唔用 PLA？PLA 硬但脆，撞一下就崩。保護框係要反覆裝拆嘅配件，需要韌性，所以用 PETG 更合適。PETG 嘅代價係表面比較容易起絲，但功能件唔影響。

批量打印建議：一次過排滿一板去印，比逐個印省時間。開頭嘅準備時間同換料時間係固定成本，一板印十個同印一個嘅差距遠比想像中細。

三項實測

  1. 「啪」一聲 fit 位 — 卡磚推入去，最後一兩毫米有輕微阻力，跟住就定位。唔需要用力壓，亦唔會鬆。
  2. 倒轉搖 10 秒 — 裝好嘅卡磚倒轉用力搖，冇一塊跌出嚟。
  3. 疊高抽中間 — 疊 20 塊再抽中間嗰塊，上下都唔會塌。

三項測試都係用同一個 v9 樣本做，冇用膠水、冇用磁石、冇任何額外零件。

常見問題

需要打印支撐嗎？

唔需要。保護框係垂直外牆結構，加支撐只會浪費時間同材料，仲會在框內留下痕跡，影響緊配合。

擴充嘅卡磚都 fit 嗎？

卡卡頌所有版本嘅卡磚都係標準 45mm × 45mm，所以 base game 同擴充嘅尺寸一致，同一個框全部通用。

一副卡卡頌要印幾多個？

視乎你玩幾多人同用幾多擴充。3D 打印嘅好處係要幾多印幾多，之後加擴充再加印就得，唔需要一次過買一套。

English FAQ

Does it fit tiles from expansions?

Yes. All Carcassonne tiles share the same 45mm × 45mm standard, so the same frame fits the base game and every expansion.

What print settings should I use?

PETG, 0.2mm layer height, 3 walls, 15–20% infill, no supports. A slightly tighter first layer improves the press-fit feel.

How many frames do I need?

It depends on player count and expansions. Because it is a 3D print, you print exactly as many as you need and add more later.
