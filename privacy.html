隱私政策 — Google 資料存取

最後更新：2026 年 10 月 9 日

本頁說明 UNITARY 的個人助理工具（下稱「本應用程式」；Google OAuth 用戶端名稱 copaw）如何透過 Google API 存取、使用及儲存你的 Google 資料。

一句話總結：本應用程式只在你本人主動發出指令時，於你自己的裝置上直接讀取或修改你的 Google 資料。資料不會傳送到我們或任何第三方的伺服器，亦不會被出售或分享。

1. 適用範圍

本應用程式為個人自用工具，只供帳戶擁有人本人的 Google 帳戶使用，並非對外提供服務的產品。此政策涵蓋本應用程式經 Google OAuth 授權後所存取的所有資料。

2. 我們存取的 Google 資料

經你同意後，本應用程式可能存取以下 Google 服務，實際範圍以你在同意畫面勾選的權限為準：

服務權限用途
Gmailgmail.modify搜尋及讀取郵件、撰寫草稿、寄送與回覆、管理標籤（不含永久刪除）
Google 日曆calendar讀取、建立及修改日曆與活動、查詢空閒時間、建立 Google Meet 連結
Google Drivedrive列出、讀取、上載、更新及整理你的檔案
Google Taskstasks讀取、新增、更新及完成任務
聯絡人（People API）contacts讀取、搜尋及新增聯絡人
Sheets / Docs / Slidesspreadsheets、documents、presentations建立及編輯試算表、文件與簡報
Google Formsforms建立表單、讀取回覆
YouTubeyoutube、youtube.force-ssl管理播放清單、影片資料及留言
帳戶基本資料userinfo.email顯示已連接的帳戶電郵，用於多帳戶辨識

3. 資料用途

所存取的資料僅用於執行你當下要求的操作，例如：

  • 你問「我今個星期有咩會議」→ 讀取日曆活動並回覆你；
  • 你叫「幫我加一個任務」→ 在 Google Tasks 建立該任務；
  • 你要求「搵返嗰封講報價嘅 email」→ 搜尋並讀取相關郵件內容。

我們不會將你的資料用於廣告、個人檔案建立、行為分析、機器學習模型訓練，或任何與上述目的無關的用途。

4. 資料儲存位置與保留

  • OAuth 權杖（access token / refresh token）以檔案形式儲存在你本人的裝置上，檔案權限設為僅本人可讀。
  • 除權杖外，Google 資料只會在該次操作期間即時讀取，不會建立額外副本，亦不會上載到我們或第三方的伺服器。
  • 對話與操作紀錄可能保存在你本機的助理工作目錄內，用於你的個人記錄；你可隨時自行刪除。

5. 資料分享

我們不會出售、出租、交易或以任何形式將你的 Google 使用者資料提供給第三方。資料只在你本人的裝置與 Google API 之間直接傳輸。

6. 你的控制權與撤銷授權

你可隨時撤回授權，無需通知我們：

  • 前往 Google 帳戶 → 安全性 → 第三方應用程式與服務，移除本應用程式的存取權；
  • 或直接刪除本機上的權杖檔案，本應用程式即無法再存取你的資料。

撤銷後，本應用程式將無法再讀取或修改你的 Google 資料；已存在於 Google 服務內的內容則不受影響。

7. 對 Google API 服務使用者資料政策的承諾

本應用程式對 Google API 所取得資訊的使用，遵守 Google API 服務使用者資料政策，包括其中的有限使用（Limited Use）要求。
